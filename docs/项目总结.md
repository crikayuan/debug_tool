# 调试助手 · 项目总结

> 交付时间：2026-10-12
> 当前版本：1.0.0
> 状态：本轮开发告一段落，后续按新需求迭代

---

## 一、项目是什么

一款 Windows 桌面端 **网络 / 串口调试助手**，NetAssist 风格，打包成独立 exe 双击即用。
面向码头 / 泊位现场调试场景：连 RS485 设备、连网络设备、收发 HEX 报文、批量发指令。

**核心定位**：单进程、免安装、离线可用、数据存本机。

---

## 二、技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | FastAPI + uvicorn | 内嵌 HTTP + WebSocket 服务 |
| 桌面壳 | pywebview | 用 WebView2 承载前端，提供原生窗口与文件对话框 |
| 打包 | PyInstaller（onedir） | onefile 模式找不到 WebView2 DLL，改用 onedir |
| 前端 | Vue 3 + Element Plus + Vite | 单页三栏布局 |
| 实时推送 | WebSocket | `select` 轮询 + asyncio 推送收发数据 |
| 持久化 | 本机 JSON 文件 | `%LOCALAPPDATA%\调试助手\store.json` |

**为什么用 Web 技术做桌面程序**：UI 迭代快、Element Plus 组件齐全、跨平台潜力；代价是要处理打包与服务端口等工程问题。

## 三、功能清单

### 网络调试
- TCP Client / **TCP Server** / UDP
- Server 模式本地 IP 下拉：**按 有线 → 无线 → 虚拟 → 回环 → 其他 排序**，每项标注网卡类型（如 `192.168.4.61 · 有线`），默认选中第一个有线 IP
- TCP Server 多客户端管理：客户端列表、广播、定向发送、单独断开

### 串口调试
- 显示**真实串口号**（CH340 等），已按需求去掉 DTR / RTS 信号选项

### 发送
- **默认 HEX 发送**
- **发送内容无长度限制**：1 个字符到 32 万字符都能发
- HEX 宽容解析：奇数长度自动左补 0（`1` → `0x01`、`ABC` → `0A BC`），非 HEX 字符按文本原样发
- 结束符：`无 / \r / \n / \r\n`
- 自动校验：sum / xor / lrc / crc16 / fcs

### 日志
- 保存调用**系统文件夹选择对话框**，**记住上次位置**
- 默认文件名 `debug_年月日_时分秒.txt`（加时分秒避免同天覆盖）
- 暂停显示按钮（发送按钮左侧，橙色标识，暂停时显示待显示行数）

### 右栏模块
- **快捷指令**：永久持久化，误删不会冒出默认数据
- **批量发送**：表格形态（编号 / 延迟 / 重复 / 数据 / 备注），左下角 `+` 添加，支持 ASCII / HEX / FILE 三种类型，循环方式可选 循环1次 / 无限循环 / 指定循环
- 历史发送、自动应答、Modbus 拼帧、工具箱、设置

### 工程特性
- **支持多开**：启动前扫描 20001~20050，自动分配端口，窗口标题带实例序号
- 左栏默认只展开「连接参数」，其余分区保持闭合
- 右栏与中栏**并排动态布局**，互不遮挡，可拖动调宽
- exe 图标：用户指定图片，含 16/24/32/48/64/128/256 七种尺寸

### 明确排除（按需求）
- 粘包 / 分包处理
- Modbus 从机模拟

## 四、关键工程决策与踩过的坑

这部分是本项目最有复用价值的内容。

### 打包相关

| 问题 | 根因 | 解法 |
|---|---|---|
| `--clean` 打包失败：`SHFileOperationW 失败: 0x2` | PyInstaller 调 `shutil.rmtree` 被安全策略 shim 拦截 | **不加 `--clean`**；先把 `dist/` 改名或清空再构建 |
| Python 脚本批量 `os.remove` 中断 | `[safe-delete] BULK_GUARD state lock timeout` | 改用 **robocopy /MIR** 做覆盖式更新 |
| robocopy 报「无效参数 #3」 | Git Bash 把 `/MIR` 转成 POSIX 路径 | 执行前 `export MSYS_NO_PATHCONV=1` |
| 覆盖 exe 时文件被占用 | 有实例在跑，进程名是中文 `调试助手.exe`，`tasklist` 按英文名抓不到 | 用 psutil 按 exe 路径匹配并结束进程 |
| onefile 模式找不到 WebView2 DLL | 解压临时目录路径问题 | 改用 **onedir**，并在 spec 里显式收集 DLL |
| 无控制台 exe 启动崩溃：`NoneType has no attribute isatty` | `console=False` 下 `sys.stdout` 为 None，uvicorn 配日志时调用 `isatty()` | 启动线程里兜底重定向 stdout/stderr + `log_config=None` |
| 多开时两个实例抢同一端口 | 扫描与绑定之间有竞态 | **先 bind + listen 拿到 socket**，再交给 `uvicorn.Server.run(sockets=[sock])` |

### 网络与协议

- **Windows 不能设 `SO_REUSEADDR`**：会让多个进程抢占同一端口，破坏多开端口分配逻辑
- **TCP Server 的 accept 依赖 WebSocket 消费循环**：`read_data()` 只在被轮询时才 accept，所以端到端测试必须建立真实 WS 连接，否则连上的客户端不会被登记
- 判定「端口上跑的是不是本程序」：请求 `/health` 看是否返回 `healthy`，用来区分「已开的调试助手」和「别的程序占用」

### 调本机接口时

- 本机 curl 调后端必须加 `--noproxy '*'`，否则走环境代理返回 502
- PowerShell COM、reg.exe 会被安全策略拦截，改用 Python `winreg` / `ctypes ole32`

### 网卡分类（本地 IP 排序）

- 用 ctypes 调 `GetAdaptersAddresses` 读 IANA ifType（6=以太网、71=Wi-Fi、24=回环、53=虚拟、131=隧道）
- **坑**：`IP_ADAPTER_ADDRESSES.PhysicalAddress` 是 `CHAR[8]`（8 字节）不是 `WCHAR[8]`。按 16 字节定义会让后续字段整体错位 +4，表现为读出 `MAC长度=1500`、Wi-Fi 的 `ifType=12`（正确应为 71）。通过 dump 原始字节定位到真实偏移才修好

### 图标

- Pillow 生成多尺寸 ICO：`append_images=` 参数对 ICO 无效（只存 1 张），要用 `sizes=[...]`，且需先把源图放大到 256 才会包含最大尺寸
- 沙箱内访问不到用户给的 `D:\google\...`，改用 WorkBuddy 缓存的 blob 副本

## 七、后续迭代建议

- 若要做在线版：把后端端口改为读环境变量 `$PORT`，前端 API 基址改为同源相对路径
- 若要加协议：现有 `services/` 与 `routes/` 分层清晰，新增协议照 `net_service` / `serial_service` 的模式加即可
- 若要改图标：覆盖 `netassist/backend/icon.ico` 后重新打包
